# Counter Program

A simple JavaScript counter application.

## Features

- Increment, decrement, and reset counter
- Responsive UI
- Easy to use

## Installation

1. Clone the repository:
    ```bash
    git clone https://github.com/yourusername/Counter-Program.git
    ```
2. Navigate to the project directory:
    ```bash
    cd Counter-Program
    ```

## Usage

Open `index.html` in your browser to use the counter.

## Technologies

- HTML
- CSS
- JavaScript
